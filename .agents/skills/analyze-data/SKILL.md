# Анализ данных

- Перед расчётом определите единицу наблюдения, период, размер выборки и знаменатель. Проверьте пропуски, дубликаты, единицы и несопоставимые сегменты. Пустая ячейка XLSX может означать отсутствующее кэшированное значение формулы. Формулы из файла не исполняются.
- Используйте локальный расчёт по исходнику, а для общего вывода сохраните команду, версии входов и результат. Перепроверьте контрольный пример вручную или независимым способом. Укажите диапазон строк или лист. При отсутствии данных для ставки, спроса или дохода укажите сценарную формулу и допущения.
- Технический эксперимент на авторских образцах даёт наблюдение о проверенной конфигурации. Применимость результата к пользовательским загрузкам остаётся отдельной гипотезой. Для расчёта запишите инструмент, результат или ошибку и длительность в `run.tsv` через `log`.
