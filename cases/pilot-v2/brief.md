# Бриф пилота

Исходный вопрос в `request.md`. Решение для владельца прототипа на следующий цикл — сохранить ручную выписку тезисов, закрыть инициативу импорта или испытать узкий импорт таблицы. Цель — сократить усилие до получения проверяемого реестра, сохранив привязку каждого тезиса к источнику.

Аудитория в учебном сценарии — продуктовые аналитики небольших команд с локальными таблицами. Допущение для обратимого шага — достаточно технической проверки и проектирования эксперимента. Для вывода о спросе нужны наблюдения пользователей.

Входы и предел прямого запроса заданы в `inputs.json`. Сбор ограничен этими тремя источниками и одним расчётом по таблице. Поиск иных страниц, оплачиваемые действия и изменение продукта не входят в пилот. Показатели потребления модели в текущем чате недоступны.

## Ревизия доказательств

Эта ревизия исправляет привязки C-001, C-002 и C-013 из [исходного пилота](../pilot/brief.md). Родительская [контрольная точка](../pilot/state.json) имеет SHA-256 `a7733b465c25bebdda4c6ff8b4c4f26f899eb991cc76c0d04b923b768296d319`. ID утверждений сохраняют связь между ревизиями. Локальные входы S-001@1 и S-002@1 скопированы байт в байт. Для расширенного фрагмента той же страницы RFC используется S-003@2. Лимит прямых HTTP-запросов CLI в этой ревизии равен нулю. Сверка разрешённого URL выполнена встроенным веб-инструментом Codex в рамках стабилизации. Продуктовый выбор остаётся за владельцем.
