# «Ритм». Продукт и аналитическая выгрузка

**SYNTHETIC TEST DATA** · авторский документ для вымышленного сервиса. Даты и измерения в приложенных CSV синтетические.

«Ритм» — мобильный планировщик домашних дел и личных задач для iOS и Android. Пользователь приходит из поиска, платного объявления или по приглашению. При регистрации ему предлагают выбрать цель, затем он попадает на экран «Сегодня». На этом экране можно создать задачу с нуля или взять шаблон. В карточке можно задать повтор и включить напоминание. Задачу можно отметить выполненной. Быстрое выполнение из шаблона может сразу записать выполнение без отдельного события создания. Повторяющаяся задача затем появляется в списке к следующему сроку. Напоминание может вернуть пользователя на карточку, но открытие карточки ещё не означает выполнения задачи.

В команде «активацией» иногда называют добавление первой задачи. Команда жизненного цикла пользуется признаком завершения настройки из старого дашборда. Этот флаг приходит отдельной выгрузкой, его полное определение утрачено. Продуктовый смысл возврата зависит от выбранного события. Для пользователя с еженедельной задачей день полезного действия может сдвигаться.

## Схема экспорта

Во всех CSV поле `data_label` маркирует строки как SYNTHETIC TEST DATA. Даты календарные в UTC. Когорты регистрации недельные, с понедельника по воскресенье.

- `signups.csv` — реестр зарегистрированных аккаунтов. `user_id` — ключ. `signup_date` — день регистрации, `cohort_week` — понедельник её недели, `platform` — платформа при регистрации, `channel` — последняя записанная метка привлечения (`organic`, `paid_social`, `referral`), `stated_goal` — необязательный ответ (`routine` — регулярные дела, `one_off` — разовые). `legacy_setup_flag` принимает `1`, `0` или пустое значение. Пустые поля означают отсутствие записи.
- `events.csv` — продуктовая телеметрия, соединяется с реестром по `user_id`. `event_id` — идентификатор сообщения, `event_date` — день события. `task_created` — создание задачи, `task_completed` — отметка о выполнении, `reminder_enabled` — настройка напоминания, `reminder_opened` — переход из напоминания, `app_open` — открытие приложения, `background_sync` — фоновая синхронизация. Экспорт допускает повторную доставку сообщения. В течение дня возможны несколько разных событий одного пользователя. Реестр регистраций формируется отдельно.
- `coverage.csv` — календарь полноты продуктовой телеметрии по паре `event_date` и `platform`. Значение `complete` означает, что по этому дню экспорт полон. Значение `partial` означает, что часть телеметрии могла потеряться. Дни после последней даты в календаре ещё не выгружены. Календарь относится к событиям. Реестр регистраций полон для указанных в нём недель.

Выгрузка содержит настройки и переходы из напоминаний. Факты отправки, доставки и показа уведомлений отсутствуют. Наличие функций у конкурентов можно подтвердить по их справке. Справка не содержит данных о том, как эти функции влияют на удержание пользователей «Ритма».
