# Паспорта проектной проверки

Все параметры здесь — проект для обсуждения, не наблюдения и не утверждённый протокол. Основания: C-014, C-016–C-019, C-023–C-024, C-028, C-030–C-031, C-041; S-001@1 page:7–9. Исходных клиентских записей нет. Числа пропусков, исключений, событий и темп набора неизвестны. Файл создан до расчёта `strategy_calculate.py`.

## Единица, окно, состав

Рандомизация 1:1 и анализ — уникальное домохозяйство/семейная группа, один первый подходящий случай за весь набор. До назначения проверяются совместимый тариф, действующее разрешение на остаток, полномочия организатора, свободный общий объём, отсутствие текущего ограничения и технически регистрируемый низкий остаток. Порог низкого остатка L, допустимая задержка данных T и резерв общего пакета R пока неизвестны: владелец биллинга и аналитик должны выбрать и заморозить их по теневому наблюдению до пилота. Задним числом подбирать L под пользу запрещено проектом.

Если одновременно подходят несколько номеров, индексный — с самым ранним событием, при равенстве — минимальный обезличенный ID. Остальные номера фиксируются на t0 для защитной метрики. Общие пакеты и люди в нескольких группах объединяются в один кластер; если это невозможно без потери сопоставимости — эксперимент не начинается. Это защищает допущение независимых семей в расчёте.

Время t0 — первый подходящий случай; исходы в [t0,t0+168 часов), все времена хранятся в UTC, отчёт Europe/Moscow. Набор проектно 6 недель плюс 7 дней созревания и до 7 дней сверки. Дата среза будущего пилота не назначена. Никаких реальных наборов сейчас нет. После назначения выход из группы, неоткрытие сообщения и отзыв разрешения не исключают семью из ITT; работа с данными после отзыва требует отдельно допустимого агрегированного учёта. Если его обеспечить нельзя, исход считается неизвестным, а не нулём.

## Полное правило решения до расчёта

Для ограниченного расширения O-03 нужны одновременно: (1) нижняя односторонняя 97,5% граница Δ >0 и оценка Δ≥3 п.п.; (2) верхняя односторонняя 95% граница вреда G1 <1 п.п. и G2 <0,2 п.п.; (3) G3 и G4 в пределах выше, primary остаётся положительным и ≥3 п.п. при худшем заполнении пропусков; (4) нет G5/G6, проверены отзыв, повтор, гонки и восстановление; условный верхний 95% предел редкого исхода при нуле событий ≤0,1% на соответствующий знаменатель; (5) подтверждены стоимость, ресурс и экономический предел вложений. Нулевые события не гарантируют безопасность.

Параметры: односторонняя α primary=0,025, минимально полезная оценка 0,03, целевой истинный эффект для планирования 0,045. Гипотеза о пользе единственная. Защитные условия обязательны все (пересечение тестов неухудшения), их α=0,05 по каждому условию; это не одновременные 95% интервалы и не право выбирать удачную метрику. Подгруппы/другие окна — разведочные, не основание запуска; для новых подтверждающих гипотез нужен новый протокол и контроль множественности. Промежуточных проверок пользы нет, досрочное завершение только по вреду/сбою; анализ primary один после фиксированного N и полного окна. При истечении срока с недостаточным N — неопределённость, новый план, не успех.

Будущий анализ: стратификация назначения по тарифу и размеру семьи; оценка стандартизуется по весам всего включённого набора, включая неизвестный размер отдельной категорией. Для простого расчёта ниже приняты независимые семьи, равные плечи, полная наблюдаемость, одинаковые риски внутри сценария. В окончательном протоколе — интервал разности долей score/Newcombe или рандомизационный интервал, подходящий для редких исходов. Нормальная аппроксимация ниже — чувствительность планирования, её нельзя выдать за точную маловыборочную гарантию.

## Наблюдаемость и чувствительность

Нужен сверяемый поток: все проверенные семьи → неподходящий тариф → нет прав → нет свободного остатка → уже ограничены → нет достоверного риска → подходящие → назначенные → окно незрелое → окно зрелое, но исход неизвестен → полностью известные исходы. Причины до включения учитываются в этом порядке однократно. После назначения остаётся полный знаменатель, в отчёте отдельно k_known/n_all и неизвестные u/n_all. Для истинной доли при неизвестных границы k/n и (k+u)/n. Для пользы худшая разность k_C/n_C−(k_T+u_T)/n_T, лучшая (k_C+u_C)/n_C−k_T/n_T. Интервалы также пересчитываются для крайних заполнений. Если вывод меняется, расширение не допускается.
