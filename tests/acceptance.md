# Фактическая приёмка прототипа

Проверено 9 ноября 2026 года по сценариям [плана](../docs/delivery-plan.md). Это приёмка минимального пути. Конкурсный демонстрационный проект готовится отдельно.

На исходной приёмке команда `python -m unittest discover -s tests -v` выполнила 17 проверок без ошибок. Четыре skill-файла прошли проверку формата.

## Стабилизация 9–10 ноября 2026 года

- **Инвентаризация.** На входе `main` без коммитов, индекс пуст, проектные файлы неотслеживаемые. В Git сохранилось дерево с ранними версиями двух проектных документов. Оно не позволяет установить авторство изменений в CLI, тестах или пилоте. Исходный снимок рабочей папки сохранён перед правками. Архив и извлечённая копия использованы для сверки всего `cases/pilot` и исторического `tests/codex-cli-run.tsv`. Файлы совпали побайтно.
- **Автоматизация.** В Python 3.13.5 установлены зависимости из `requirements.txt`, `pip check` прошёл. Все 23 теста прошли. Проверки структуры используют временные фикстуры, в том числе для недостающего аудита, пропусков, дублей, неизвестного ID, пустого обоснования, неверного вердикта и записи `needs_revision`. Отдельная фикстура показывает, что правильно оформленный, но необоснованный вердикт проходит проверку структуры. Проверены изменённый захват, повтор локатора и восстановление записи стратегии из журнала после сбоя до обновления состояния. Изменение завершённого аудита блокирует `verify` и `resume`. Проверка подтверждения решения в наборе использует заглушку в отдельной временной папке.
- **Сохранённые кейсы.** `verify` обоих кейсов принял 3 источника и 17 утверждений. Для исходного пилота результат аудита `legacy_unrecorded`, для [ревизии 2](../cases/pilot-v2/quality.md) — `checked`. `resume` обоих кейсов вернул `awaiting_decision` и следующий шаг `decision`. Скрипт на восьми авторских файлах повторно воспроизвёл CSV байт в байт. Независимый пересчёт подтвердил 5 принятых файлов, 3 отклонённых и 0 несовпадений.
- **Смысловая оценка.** В текущем сеансе Codex все 17 утверждений сверены по `check-evidence`. [Обоснования](../cases/pilot-v2/audit.tsv) относятся к локальным первичным фрагментам, расчёту и цепочкам оснований. C-001 и C-002 используют полные абзацы исходного DOCX. C-013 использует расширенный захват S-003@2 того же разрешённого RFC. Стратегия сохранена побайтно. Новые сквозные испытания с LLM и исследовательские прогоны отсутствуют. Прежние два запуска Codex CLI описаны ниже. Токены и стоимость текущей сверки неизвестны.
- **IDE.** Четыре единственных исходника skills размещены в `.agents/skills`. Путь поддерживается по документации обеих IDE. Codex CLI 0.166.0-alpha.6 обнаружен, локальная проверка `skills/list` упёрлась в ограничения доступа при запуске app-server. Cursor 3.29.9 установлен, проверка через интерфейс завершилась по тайм-ауту. Обнаружение в запущенных IDE и перенос кейса между ними остаются открытыми. [Codex](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills) · [Cursor](https://prod.cursor.com/help/customization/skills)
- **Ограничения.** T7 на пилоте ждёт решения владельца. Прямой HTTP через CLI, полноценный запуск в Cursor, второй продуктовый кейс и измерение затрат остаются открытыми. Пилот пока не измеряет спрос, экономию времени и поддержку.

## Сквозные прогоны

- В рабочем сеансе Codex пройден путь от исходного запроса до [стратегии пилота](../cases/pilot/strategy.md). Входы — авторский DOCX, измеренный технический CSV и проверенный фрагмент публичного RFC. Прямой запрос CLI вернул ошибку DNS. Разрешённый снимок использован после чтения [RFC Editor](https://www.rfc-editor.org/rfc/rfc4180.html#section-2) встроенным веб-инструментом. Отдельная попытка с доступом к сети остановилась на проверке публичности адреса. Успешное прямое чтение страницы CLI в этой среде не подтверждено.
- После исследования сделана пауза. Команда `resume` в новом процессе восстановила следующую фазу, а валидация прошла для трёх источников и 17 утверждений. Пилот остановился в `awaiting_decision`. Расход модели в этом сеансе не наблюдался. [Журнал пилота](../cases/pilot/run.tsv).
- Отдельно в чистой временной копии проведены **два независимых запуска Codex CLI 0.166.0-alpha.6** с реальной моделью по доступу CLI. В копию передали инструкции, код и исходники, без артефактов предыдущего прогона. Первый запуск выполнил исследование и остановился перед стратегией. Второй получил только путь к кейсу и продолжил без истории чата. Он сравнил сохранение курса, закрытие и узкий CSV-пилот, предложил замер ручного пути перед вложением в разработку и завершился в `awaiting_decision`. Итоговые артефакты прошли независимый запуск валидации для трёх источников и 15 утверждений. Повторного извлечения источников во втором сеансе в журнале нет. [Журнал двух сеансов](codex-cli-run.tsv).
- Скрипт повторно воспроизвёл исходную таблицу совместимости байт в байт. Из восьми авторских образцов пять были приняты, три отклонены. Все восемь наблюдений совпали с ожидаемой классификацией. Это результат технической проверки, а спрос, экономия времени и расходы на поддержку пока неизвестны.

### Измерения Codex CLI

Значения взяты из двух событий `turn.completed` CLI. Кэшированные входные токены входят в число входных. Разбиение показывает нагрузку всего сеанса, включая работу с инструментами. Имя фактически использованной модели и денежная стоимость в этих событиях не раскрыты.

| Новый сеанс | Входные токены | Из них из кэша | Выходные токены |
| --- | ---: | ---: | ---: |
| Постановка и исследование | 134 981 | 116 736 | 3 607 |
| Восстановление и стратегия | 166 120 | 133 376 | 4 513 |

В журнале независимого прогона отмечены интервалы между командами начала и завершения исследования и стратегии, около 50 и 78 секунд соответственно. Это интервалы фаз внутри сеансов. Полное время работы человека и модели ими не измерялось. Первый сеанс прочёл реализацию CLI без необходимости, а второй загрузил весь журнал и все выписки. В инструкциях после проверки ограничено чтение текущей фазой и нужными фрагментами. Замера экономии после правки пока нет.

## T7. Учебное решение и адресный пересмотр

Владелец подтвердил O-03 в [D-001](../cases/pilot-v2/decisions.md). Родительский кейс восстановлен в `decided`. В отдельной ревизии [pilot-v3](../cases/pilot-v3/brief.md) сохранены ссылка и хеши родительского решения и состояния. Проверка хешей всех файлов обоих исторических кейсов до и после показала полное совпадение.

В текущем сеансе Codex агент применил skills к двум новым тестовым материалам. По `S-004@1` выполнены парный расчёт, независимая сверка и разбор зависимостей. Медиана 11,5% ниже проектных 20%. `S-005@1` исключён по содержанию. Открытая рекомендация O-06 уточняет протокол замеров. [Расчёт и зависимости](../cases/pilot-v3/research.md) · [Рекомендация и обязательства](../cases/pilot-v3/strategy.md)

Две новые автоматизированные проверки воспроизводят метрики по одному CSV и восстанавливают пересмотр в новом процессе по файлам с привязкой к родительскому решению. `verify` прошёл для обеих ревизий. `pilot-v3` остался в `awaiting_decision` без записи выбора. Архитектура и схема CLI прежние. Модельная часть выполнена в текущем сеансе Codex на фикстурах. Независимого модельного прогона в новом чате и реальных наблюдений пользователей для этой проверки не было.

## Статус сценариев из плана

| Сценарий | Подтверждено | Оставшаяся проверка |
| --- | --- | --- |
| T1. Чистый запуск и постановка | Реальная модель Codex CLI сформировала бриф и запустила исследование по общим инструкциям. | Чистый запуск в Cursor. Cursor в доступной среде не обнаружен. |
| T2. Источники и пробелы | DOCX, CSV и подтверждённый снимок RFC в обоих прогонах. Успешно проверены ID, локаторы и фрагменты. Ошибки доступа сохранены. | Прямой HTTP на разрешённой сети и кейс с конфликтующими источниками и перепечаткой. |
| T3. Варианты и стратегии | Две проверенные стратегии в двух реальных прогонах. Есть три направления, сильные возражения, экономическая модель и измеримый план проверки. | Прогон стратегии в Cursor. |
| T4. Повтор расчёта | Генерация CSV из выполненного технического теста, повтор сводки и независимый пересчёт. PDF, DOCX, CSV и XLSX извлечены в автоматизированных проверках. | Полевой датасет с пропусками, разными периодами и единицами в модельном прогоне. |
| T5. Продолжение и сбой | Новый сеанс Codex CLI без истории продолжил по файлам. Отдельные тесты покрыли частичный выход, сохранённый журнал до обновления состояния и повторное использование источника. | Перенос между Codex и Cursor. |
| T6. Границы доступа и бюджет | CLI проверил лимит веб-запросов, отказ от выхода за пределы `inputs/`, запись недоступного источника, блок повторного запроса с неясным исходом и хранение вредоносной строки как данных. | Отдельный модельный прогон с внедрённой инструкцией. |
| T7. Решение и пересмотр | Владелец подтвердил учебное D-001. В отдельной ревизии разобран синтетический результат ниже порога и исключён нерелевантный документ. Родительский выбор сохранён, пересмотр ждёт подтверждения. | Подтверждение предложенного изменения и проверка на полевых данных выходят за рамки этого прогона. |
| T8. Второй кейс | Проверки работали в отдельных временных папках. | Второй сквозной продуктовый кейс с новой задачей и источниками. |
| T9. Прозрачность затрат | Записаны ошибки, повторы, интервалы фаз, измеренные токены CLI и неизвестная денежная стоимость. | Человеческие трудозатраты и сравнение с обычным чатом при одинаковых условиях. |
