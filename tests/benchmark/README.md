# Подготовленный сравнительный эксперимент

**Статус: не запущен.** Модели не вызывались для исследования, стратегии не создавались. Подготовлены чистые рабочие копии; техническая граница чтения между ними и исходным репозиторием **не установлена**. Без дополнительной проверенной изоляции возможен только пилот с этим ограничением, а не строго независимый слепой запуск.

| Режим | Точный путь на хосте подготовки | Начальный состав |
| --- | --- | --- |
| A — LLM с инструментами | `/private/tmp/strateg-benchmark-A-20261113` | 15 общих файлов, без AGENTS.md, skills, workflow и прежних результатов |
| B — агент | `/private/tmp/strateg-benchmark-B-20261113` | Те же 15 файлов плюс AGENTS.md, четыре актуальных skill и workflow |

В каждом варианте семь одинаковых файлов исходных данных. В копиях нет Git, эталона, тестов, старых отчётов, T8-результатов, символических и жёстких ссылок; общих inode нет. Эти проверки относятся к **составу копий**, а не к правам чтения остальных файлов хоста.

## Состав пакета оператора

- [protocol.md](protocol.md) — дизайн, одинаковые условия, ограничения изоляции и последовательность действий в Codex.
- [environments.json](environments.json) — полный манифест A/B: имена, размеры, SHA-256, происхождение и версии инструкций.
- [prompts/A.md](prompts/A.md) и [prompts/B.md](prompts/B.md) — побайтно одинаковые нейтральные запросы; их копия `START.md` есть в каждой среде.
- [rubric.md](rubric.md) — численные показатели N1–N6 и экспертные критерии E1–E10, без бонуса за совпадение с прежней рекомендацией.
- [recording.md](recording.md) и [templates/](templates/) — фиксация модели, времени, usage, денег, ручных действий, упаковка и слепая оценка.
- [prepare.py](prepare.py) — воспроизводимая сборка по явному allowlist и проверка начального/конечного состояния; существующие копии не перезаписывает.
- [preparation-check.json](preparation-check.json) — реальные проверки подготовки и runtime, включая неизвестные значения.
- [registration.json](registration.json) — SHA-256 манифеста, протокола, рубрики, промптов, шаблонов, скрипта и отчёта подготовки. Это локальная фиксация, не внешняя временная отметка.

Пакет оператора не открывать из исследовательских чатов. Копии вне репозитория не наследуют его родительский AGENTS.md, но глобальный контекст приложения требуется проверить отдельно. Временные каталоги `/private/tmp` не являются долговременным хранилищем; для переноса предусмотрен transport-манифест с повторной проверкой хешей.

## Как запускать позднее

1. Оператор выполняет из исходного репозитория `python3 tests/benchmark/prepare.py verify tests/benchmark/environments.json`. Проверяет зарегистрированные хеши и передаёт их независимому хранителю до запусков.
2. Обеспечивает подтверждённую изоляцию чтения и одинаковые чистые профили, либо явно регистрирует ограниченный пилот. Заполняет **копию** `templates/launch.json`, не меняя замороженный шаблон.
3. Добавляет A и B в Codex как отдельные рабочие папки/проекты, создаёт два новых чата без истории этого проекта. Запланированы `gpt-6.1-sol`, effort `medium`, 30 минут и 120 обращений на каждый режим. Выбор модели/effort и фактические настройки проверяются перед обоими стартами; локальный config не доказывает будущую серверную версию.
4. Сначала в чат A отправляет весь `prompts/A.md`, затем в отдельный чат B — весь `prompts/B.md`. Отсчёт времени и инструментов начинается с отправки. Методы A свободны; инструкции B поступают из его проекта. Подробные одинаковые правила остановки — в протоколе.
5. Запечатывает каждый сырой результат, не улучшая его после лимита. Независимый хранитель обезличивает оба пакета. Приёмщик отдельно пересчитывает числа, эксперты слепо оценивают содержание по рубрике. Соответствие A/B и затраты раскрываются после фиксации оценок; полная слепота по стилю не гарантируется.

Один запуск на знакомом разработчику кейсе даёт локальное сравнительное свидетельство. Он не доказывает универсальное улучшение качества агента.

## Что реально проверено

13 ноября 2026 года: оба allowlist-инвентаря прошли, все общие файлы совпали, каждый файл независимо сравнен с разрешённым оригиналом. `python3 -m tools.case --help` успешно выполнен в каждой копии с выключенной записью bytecode; модель и фазы кейса не запускались. Системный Python 3.13.5 пригоден для данных этого формата; наличие необязательных сторонних пакетов явно записано, `.venv` в копии не передавалась.

В проектном `.venv` команда `python -m unittest discover -s tests -v` прошла **45 тестов за 36,521 с**: 37 прежних и 8 новых проверок упаковки. Новые тесты используют маленькие искусственные файлы и проверяют равенство, лишние материалы, изменение входов, ссылки, защиту от перезаписи и режим проверки после запуска. Они не оценивают качество будущих стратегий. `git diff --check` прошёл; исторические кейсы, эталон и старые отчёты не изменены. Git-коммит не выполнялся.
