# Исследование источников

1. Запишите в `research.md` вопросы, у которых ответ способен поменять выбор, и признак, при котором поиск можно завершить.
2. Для каждого разрешённого входа выполните `python -m tools.case ingest CASE SOURCE`. Для разрешённого прямого веб-запроса добавьте `--live`. При ошибке сохраните её, оцените влияние и используйте разрешённый снимок, если он существует. Перед ручным веб-доступом проверьте общий лимит и зарегистрируйте действие в журнале.
3. Читайте нужные записи из `evidence/*.jsonl`. Свяжите каждый существенный факт с ID версии, точным локатором и короткой дословной цитатой. Проверьте, относится ли материал к выбранному периоду и аудитории. Повторные публикации одного первоисточника дают одно свидетельство.
4. Для расхождений проверьте определения, выборку и период. Пометьте оставшийся конфликт и укажите, какие решения от него зависят. Синтетические ответы можно использовать для поиска гипотез. Свидетельства спроса требуют реальных наблюдений. Закончите фазу кратким выводом по каждому ключевому вопросу.
