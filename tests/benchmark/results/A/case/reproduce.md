# Воспроизведение кейса «Ритм»

## Окружение и границы

Рабочий корень исходного прогона: `/Users/dima/strateg-benchmark-runs/A`. Все созданные файлы — внутри `case/`. Использован Python **3.13.5**, стандартная библиотека; полная версия сохранена в `calculations/qc.json` и первой записи `actions.jsonl`. Новые пакеты не устанавливались. Исходные брифы, разрешённые входы, START.md и поставленные tools не изменялись. Внешние источники/сеть не использованы, модельный денежный лимит не предполагался. Один основной агент, без субагентов, без коммита и без продуктового эксперимента.

Даты данных — UTC, последний экспортированный день 2026-08-12. Дата подготовки — 2026-11-13, пользовательский часовой пояс Europe/Moscow. Точные времена записей действий хранятся в UTC с явным смещением; это время записи, если начало не измерялось.

## Версии входов

`input_versions.json` содержит SHA-256 и размер в байтах для `SOURCE_BRIEF.md`, `case/brief.md`, `case/inputs.json`, всех семи файлов `case/inputs/`, `START.md` и `tools/*.py`. Это версия по содержимому, не Git revision. `source_registry.tsv` связывает S-001@1…S-007@1 с локальными файлами и их SHA-256; исходные ID взяты из неизменённого `inputs.json`.

Локальные снимки Google Tasks, Microsoft To Do и Todoist использованы только с датой захвата/описанием, указанными в manifest (2026-11-10). URL в manifest/реестре — атрибуция, не команды для обращения к сети. Содержимое данных не исполнялось как инструкции.

## Команды

Выполнять из корня проекта, используя `python3`. Скрипты находят `case/` относительно собственного файла. Команды перезаписывают только производные расчёты и дописывают локальный журнал; входы не меняют.

```sh
cd /Users/dima/strateg-benchmark-runs/A
python3 case/analyze.py
python3 case/additional_analysis.py
python3 case/sensitivity.py
python3 case/verify_local.py
```

Для другой копии заменить только путь в `cd`. Скрипт проверки не импортирует основной анализ: отдельно строит множества `(user_id,event_date)`, проверяет знаменатели по календарю и сверяет агрегаты, контрольные суммы, регистрацию источников, разложение и структуру документов. При ошибке assert/исключение дают ненулевой exit code; не считать такой прогон проверенным. Локальный CLI изучен командой `python3 -m tools.case --help`; обязательность его checkpoint-схемы в локальных инструкциях отсутствует, для данного кейса использованы собственные расчёты/журнал и независимая сверка. `tools.case verify` не запускался и его успешность не заявляется.

Числа детерминированы при тех же входах и версии скриптов. Времена в `actions.jsonl` и `verification.json`, версия Python в QC и хэши зависящих от них файлов закономерно меняются при повторном прогоне; это не изменение бизнес-результатов. Случайных выборок нет. `calculation_hashes.json` фиксирует состояние выходов последнего успешного `verify_local.py`; после повторного анализа повторить проверку для обновления хэшей.

Реализация: `analyze.py` — основа; `additional_analysis.py` — разности/ранние действия и дополнительные окна; `sensitivity.py` — парные окна и наивный знаменатель; `verify_local.py` — независимая сверка. `guardrail_sample_size.csv` создан однострочным сценарием `ceil(2*0.47*0.53*((1.644853626951+0.841621233573)/0.02)**2)`; его проверка и восстановление включены в `verify_local.py`. R1–R13 с точными фильтрами, формулами и локаторами — `research.md`. Основной документ — `strategy.md`, содержательный аудит — `quality.md`.

## Наблюдаемые действия, ошибки и затраты

`tool_calls.tsv` перечисляет фактические обращения к локальному shell по порядку; оболочка functions.exec не считается второй операцией, внутри не вызывались внешние инструменты. `actions.jsonl` фиксирует действия по мере работы и дополнен явным восстановлением read-only осмотров из наблюдаемой истории этого прогона. Точные UTC начала первых осмотров и полная длительность от сообщения пользователя **не измерены**; не подменены временем первого сохранённого лога. Времена успешных скриптов и итоги проверки являются наблюдаемыми локальными измерениями. Первое сохранённое измерение analyze.py: **1,107 с** по монотонному таймеру, только локальный расчёт (не время модели и не весь кейс).

Модель/идентификатор конкретного прогона, фактические токены и денежная стоимость: **неизвестны**, API usage/billing в разрешённых материалах отсутствуют. Тариф и денежные суммы не предполагались. Оценки человеко-дней/будущего теста в стратегии — плановые допущения, не фактическая стоимость модельного прогона. Ошибки и ненулевые exit code, если возникнут, фиксируются в журнале; итог текущей проверки следует читать в `verification.json` и конечных записях журнала.

Лимиты: 30 минут и 120 фактических обращений из запроса. Прогон завершён до лимита; число фактических обращений указано последней строкой `tool_calls.tsv`. Полная длительность не выдумывается. Все готовые файлы локальны, никаких материалов наружу не отправлено.

Итог исходного прогона: **18 фактических обращений к exec_command**; один вызов завершился exit code 1 из-за ошибки границы расширения в собственной проверке ссылок. Ошибка исправлена; повторная и итоговая проверки завершились exit code 0 (472, затем 473 сверки). Актуальный результат — `calculations/verification.json`. Внутри вызовов использованы только shell/Python, дополнительные программные инструменты не вызывались. Число 18 относится к исходной работе, повторное выполнение команд увеличит журнал отдельно.
