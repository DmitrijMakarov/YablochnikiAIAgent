## Оставшиеся действия капитана

1. Записать и загрузить видео, вставить его реальную ссылку в README и заявку.
2. Передать репозиторий. ZIP содержит рабочие файлы, материалы и результаты без `.git`, виртуального окружения, локальных кейсов, `.DS_Store` и временных файлов. Существующий remote — `https://github.com/DmitrijMakarov/YablochnikiAIAgent`; его видимость и соответствие текущим локальным изменениям в этом сеансе не подтверждались.
3. При сдаче ссылкой GitHub сначала опубликовать текущие изменения и проверить содержимое ссылки. Альтернатива — загрузить готовый ZIP на разрешённый диск с правом скачивания по ссылке.
4. Отдельно загрузить описание и стратегию PDF, если это удобнее для полей формы. В GitHub те же файлы доступны из README.
5. Проверить все ссылки в приватном окне без авторизации: репозиторий/архив, описание, демонстрация, видео.
6. Капитану отправить работу в блоке «Моя работа» и сохранить подтверждение отправки.

## Пересборка материалов

Для запуска агента достаточно корневого requirements.txt. Средства `tools/submission/` нужны только для оформления:

- `capture.py` — новые локальные проверки и извлечение фрагментов; Python с основными зависимостями. Повторный запуск обновляет свидетельства.
- `screenshots.cjs` — Playwright и установленный Chrome; страницы локальные, HTTP/HTTPS блокируются. `SUBMISSION_BROWSER` позволяет выбрать другой установленный поддерживаемый браузер.
- `build_report.py` — ReportLab, Pillow и Arial. Для иной ОС задайте каталог шрифтов через `SUBMISSION_FONT_DIR`. Источник текста — `report.json`.
- `package.py` — стандартная библиотека Python и Git; собирает ZIP, манифест и проверяет распакованную копию. Не публикует материалы и не обращается к удалённому серверу.

Для сдачи пересборка не нужна: используются готовые PDF и ZIP. Затраты неизвестны и не заменены нулём. Система не заявляет субагентов, hooks, отдельные специализированные модели, OCR, мультимедиа или фоновое сопровождение.
